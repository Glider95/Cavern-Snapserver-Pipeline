Cavern by Bence Sgánetz (http://en.sbence.hu)

For user documentation, go to http://cavern.sbence.hu/cavern/doc.php

Extract the archive anywhere and run CavernPipeServer.exe.
It will run as a taskbar icon, open the taskbar with the up arrow if the Cavern
C icon is not visible. Right click the icon to access quick settings.
